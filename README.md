# Portfolio

A personal snapshot of holdings, published as a static page so it can be opened in Safari.

- Live page: https://robertonevesjr-15.github.io/portfolio/
- Prices are refreshed daily at 2:00 AM Abu Dhabi time (Asia/Dubai, UTC+4).

`index.html` is generated from `data/holdings.json` by `make_page.py`. See `DAILY_UPDATE.md` for the nightly refresh steps.

This repository is public. Anyone with the link can see the holdings. The page is served with `noindex`.
